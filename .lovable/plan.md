

# Blank page on usdc.directory — root cause and fix

## What the user sees
The published site at `usdc.directory` shows a blank dark blue page. Fetching the HTML confirms why:

```html
<html><body><div id="root"></div></body></html>
```

There are **no `<script>` tags**. The published bundle has no JavaScript to execute, so React never mounts and even the ErrorBoundary can't render.

## Why this happened

`package.json` pins `"wagmi": "^3.6.0"`. Wagmi has no stable v3 — the current major is v2.x. Meanwhile `@reown/appkit-adapter-wagmi@1.8.19` declares a peer dependency of `wagmi >=2.19.5` and `<3`. The result:

- The lockfile resolves wagmi to a broken/prerelease artifact
- `WagmiProvider` and `wagmiAdapter.wagmiConfig` API shapes don't match what the adapter expects
- The production build either fails silently during publish or produces a broken bundle that the hosting layer drops

The local preview keeps working because it has a cached, working `node_modules` from earlier. The published deploy was rebuilt against the broken resolution and shipped an empty index.html.

## The fix (single, low-risk change)

**Pin wagmi to v2 (matches Reown AppKit v1.8 peer requirements).**

1. `package.json` — change `"wagmi": "^3.6.0"` → `"wagmi": "^2.14.11"`
2. Add `@wagmi/core` explicitly (peer of the adapter): `"@wagmi/core": "^2.16.0"`
3. Add `@wagmi/connectors` (optional peer used by the adapter): `"@wagmi/connectors": "^5.7.0"`
4. Reinstall dependencies so the lockfile picks up wagmi v2
5. No code changes needed — `Web3Provider.tsx` already uses the v2-compatible API (`WagmiProvider config={...}`, `wagmiAdapter.wagmiConfig`)
6. Republish so the new bundle ships to `usdc.directory`

## Verification after fix
- `npx vite build` produces a `dist/` with `index.html` containing `<script type="module" src="/assets/index-*.js">`
- Reload `https://usdc.directory` — page renders, header + hero visible
- Open wallet modal — no `Buffer is not defined`, no module-load errors

## Files touched
- `package.json` — pin wagmi v2, add `@wagmi/core` and `@wagmi/connectors`
- `bun.lock` / `package-lock.json` — regenerated by install
